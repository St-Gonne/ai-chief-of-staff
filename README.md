# AI Chief of Staff

A permanent memory vault on my Mac, operated by Claude. Every morning I type "Daily Briefing", two words, and it reads my goals, scans overnight meeting intelligence, walks my commitment ledger, checks my calendar, flags what's gone stale, and asks me four health numbers. Everything we agree on gets written back to files and committed to git before the day moves on.

**Status: work in progress, running daily since 5 July 2026.**

## The problem it solves

I run several professional tracks in parallel and my working memory doesn't hold a hundred threads. Anything not captured with near-zero effort was getting lost. Chat AI is great at thinking but forgets everything between sessions... so the fix was to make the memory live in plain files on disk, and make the AI operate the files.

## The rules that make it trustworthy

- **Every written claim carries a tag saying where it came from:** I said it, a meeting record says it, or the AI inferred it. A tag never upgrades silently.
- **If the vault doesn't know something, it's marked as a gap.** Guessing is not allowed.
- **If two sources contradict, it's flagged as a conflict and I resolve it.** The AI never silently overwrites.
- **The AI can only edit certain folders.** Raw records are read-only to it. There is exactly one sanctioned file it may write into the meeting system's territory, and that file is generated by a script that fails safely if the content grows past a hard cap.
- **Small git commits all day**, so nothing is ever lost and every change is auditable after the fact.
- **All outbound messages and anything involving money need my explicit approval.** The AI drafts, I send.

## Who wrote what

Claude drafts almost everything here, including most of the wording of the operating rules. The decisions are mine: what the AI may touch, what always needs my approval, what gets flagged versus quietly fixed, and which of its recommendations I've rejected (there's a record of those too).

[docs/OPERATING_RULES.md](docs/OPERATING_RULES.md) is a generalized version of the actual standing instructions the AI reads at the start of every session, with my personal data and named relationships taken out.

## What's not here

The vault's content. It's my real work, deals and health data, and it stays private. What's published is the system design, which is the transferable part anyway.
